# Agentic SDLC: Building a Software Factory

A hands-on course where you build a suite of AI agents that automate every phase of the software development lifecycle — from requirements to deployment. By the end, you will have assembled a working "software factory": a coordinated set of agents that can take a feature idea and carry it through architecture, requirements, code, tests, and CI/CD without manual intervention.

## What You'll Build

| Module | Agent | Responsibility |
|--------|-------|----------------|
| 1 | Git workflow agent | Automates issues, branches, commits, and PRs via `gh` CLI |
| 2 | Software Architecture agent | Generates arc42 documents and C4 diagrams |
| 3 | Software Requirements agent | Derives user stories, bounded contexts, and a Pareto-prioritized backlog |
| 4 | CI/CD agent | Produces GitHub Actions workflows and AWS SAM deployment configs |
| 5 | TDD/BDD multi-agent system | Runs a full test → implement → refactor loop across four specialized agents |
| 6 | Final Project | Individual kata combining all agents into an end-to-end software factory |
